# ia-formation-scripts

Public bootstrap scripts for the **ia-formation** training repo (private slides).

These files are copies of `scripts/setup-automation-lab.*` — update both repos when changing the lab installer.

## Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/JSurquin/ia-formation-scripts/main/setup-automation-lab.sh | bash
```

## Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/JSurquin/ia-formation-scripts/main/setup-automation-lab.ps1 | iex
```
